# sssync

两台 Mac 的「整机状态」手动同步器：原生 SwiftUI 应用，界面中文，只支持 macOS。

家里一台 MacBook、公司一台 Mac mini，用久了两边总会悄悄变得不一样：zsh 配置改了一边忘了另一边，App 的快捷键只在一台设过，node 版本、全局 npm 包、brew 工具装得东一块西一块，`.json` 在这台用 Zed 打开、那台用 VS Code。sssync 把两台摆在一起，**看清哪里不一样、是哪边改的，然后一条一条由你决定**：以哪边为准、两边合并，或者确认「本来就该不一样」，不再提醒。目标是把「待处理」清零，两台从此保持一致。

## 为什么不用现成的

| 工具 | 差在哪 |
|---|---|
| Unison / rsync / 网盘 | 只能整文件覆盖。一个 plist 里既有要同步的快捷键，又有本机的窗口位置，整文件同步会把后者也覆盖掉 |
| chezmoi / Mackup | 只管 dotfile 和配置文件路径；不管偏好设置里的单个键、启动项、默认打开方式、工具链和 App |
| 各种「自动同步」 | 按修改时间「新的赢」，两边都改过的时候默默丢掉一边 |

sssync 的做法：

- **粒度到一个键**：App 设置按 `CFPreferences` 逐键对比，窗口位置、版本号、更新检查时间这类噪音键内置过滤。
- **三方对账**：中转站里存着「上次两边一致时的值」（基线），所以能分清「只有家里改了」「只有公司改了」「两边都改了」。两边都改过的永远交给你拍板，文本可以三方合并。
- **每台只改自己**：本机要改的当场应用；对面要改的写成「待办」放到中转站，等对面的 sssync 下次刷新时自己执行。不经 ssh 远程执行任何东西。两台不用同时在线，家里的笔记本合着盖也没关系。
- **安全**：待办带前置条件，目标机器的当前值和你拍板时看到的不一样，这条待办就作废，不会覆盖。所有覆盖、删除前先备份，写完重新扫描校验。
- **读不到 ≠ 不存在**：某台读不到的东西（比如没给完全磁盘访问、读不到沙盒 App 的设置）整个不参与对比，绝不会当成「那台没有」去删。

## 怎么工作

```
┌──── 家里 ────┐      ┌──── 中转站（你自己的服务器，ssh）────┐      ┌──── 公司 ────┐
│ sssync.app   │ 发布 │ machines/<机器>/state.json  两边状态 │ 取回 │ sssync.app   │
│ 扫描 → 对比  │ ───► │ blobs/                      内容仓库 │ ◄─── │ 扫描 → 对比  │
│ 拍板 → 本机  │ ◄─── │ base/                       基线     │ ───► │ 拍板 → 本机  │
│ 执行给自己的 │ 取回 │ decisions/<机器>/           待办     │ 发布 │ 执行给自己的 │
│ 待办         │      │ receipts/、shared.json      回执、清单│      │ 待办         │
└──────────────┘      └──────────────────────────────────────┘      └──────────────┘
```

中转站只是一台两边都能 ssh 上去的 Linux 机器上的一个目录，不用装任何服务。每次刷新：执行发给本机的待办 → 扫描本机并发布 → 取回对面最近一次发布的状态 → 对账。

## 现在能管的

**同步（逐条拍板）**

| 类型 | 例子 | 说明 |
|---|---|---|
| 文件 | `~/.claude/CLAUDE.md`、`~/.zshrc`、`~/.gitconfig` | 逐个文件；两边都改过的文本可以三方合并 |
| 受管目录 | `~/.claude/skills`、`~/.config/zsh` | 每个顶层子目录 / 文件算一条；`local.zsh` 是本机专属，永不同步 |
| App 设置 | iTerm2、Manico（沙盒） | 偏好设置逐键对比，窗口位置、版本号、统计这类噪音键自动过滤；写入前要先退出那个 App |
| 启动项 | `~/Library/LaunchAgents` | 同名不同参的（如 rtunnel 的端口、密钥）设成模板，对比模板，写入时按本机的值填回 |
| 默认打开方式 | `.json` → Zed | `Zed` 与 `Zed i18n` 视为同一个 App |
| 密钥 | `secrets.zsh`、`.env` | 照常同步，但对比时值打码 |

**环境与应用对比**

| 页面 | 内容 | 本机缺的 / 旧的 | 只有一边有的 |
|---|---|---|---|
| 开发环境 | nvm 与 node 版本、全局 npm 包（按包对比，不管装在哪个 node 下）、uv 的 Python 与 tool、brew 主动装的工具、常用命令版本、登录 shell 生效后的环境变量和 PATH | 「在本机安装 / 升级」（nvm / npm / uv / brew 命令，边跑边看输出）；对面缺的给「复制安装命令」 | 「在本机卸载」或「让对面卸载」（nvm / npm / uv / brew 命令；默认 node 不能卸） |
| 应用 | `/Applications`、`~/Applications` 里的 App，标出来源 | brew 装的一键安装 / 升级，App Store 的打开商店页安装 / 更新 | brew 装的 `brew uninstall --cask`，其余移到废纸篓（要先退出） |

「让对面卸载」和同步一样走待办：对面的 sssync 下次刷新时自己卸，卸之前按那台当时的情况重新核对一遍，变了就不动；结果会回传到发起的这台，发系统通知。

**确认差异**：两边本来就该不同、或暂时不想处理的，在那一行点「✓ 确认差异」，它就从待处理里消失；任一边再变会重新出现。确认过的全部集中在侧栏「已确认的差异」，每条都能单独取消。没有批量确认：每条都要你自己看过再决定。「不再同步这一项」则是永远不管。

**同步清单两台共用**：在设置（⌘,）的「同步清单」里增删文件、目录、App 设置，存在中转站 `shared.json`，对面下次刷新跟着变。不知道某个 App 的设置存在哪：工具栏点「录制」→ 选 App → 去 App 里改一个设置 → 停止，勾选变了的文件和键加进清单。

**常驻**：关掉窗口后留在菜单栏，按设置的间隔（默认 15 分钟）和开盖唤醒时自动刷新；对面改了东西发系统通知。设置里可开「登录时自动启动」。

**权限**：要读沙盒 App（如 Manico）的设置，需要在那台给 sssync 开「完全磁盘访问」，读不到时界面会提示，且这个 App 暂不参与对比。

## 安装

需要：Xcode、[XcodeGen](https://github.com/yonaskolb/XcodeGen)（`brew install xcodegen`），一台两边都能免密 ssh 的服务器当中转站。下面的默认值是作者自己的两台机器（`~/.ssh/config` 里的 `new` 是中转站，`mini` / `home` 是两台互连），用在你自己的机器上先改这几处：

| 改什么 | 在哪 |
|---|---|
| 两台的 `hw.model`、名字、emoji，中转站主机和目录 | `Sources/SyncKit/Config.swift` 的 `Config.standard`（装好后也能在设置里改） |
| 默认同步清单（文件、目录、App 设置、启动项模板） | `Config.swift` 的 `SharedConfig.standard`（装好后在设置「同步清单」里改，存在中转站） |
| 签名团队、bundle id | `project.yml`，以及 `scripts/install.sh` 里校验的团队 id |
| 对面那台的 ssh 名 | `scripts/install.sh` 里的 `PEER` |

```bash
./install.sh           # 编译并装到本机和对面那台，装完自动重开
./install.sh --local   # 只装本机
```

两台都装在 `/Applications/sssync.app`（Finder 里的「应用程序」），用开发者证书签名（不是 ad-hoc），这样重装后完全磁盘访问等系统授权不会丢。

第一次打开：设置（⌘,）里确认「这台电脑是」家里还是公司（按 `hw.model` 自动认，认不出来时会自动弹出设置）。

## 用法

1. 打开 sssync 或点刷新（⌘R）：执行发给本机的待办 → 扫描本机并发布 → 和对面最近一次发布的状态对账
2. 「待同步」里每条差异一行，标签说明是谁改的（🏢 公司 新增、🏠 家里 改了、两边都改了…）
3. 点「🏠 →」或「← 🏢」拍板，「✓ 确认差异」翻篇，◫ 左右对比，⋯ 里有合并两边、设为模板、不再同步
4. 以对面为准 → 本机当场改；以本机为准 → 进「等对面应用」，对面下次刷新时执行
5. 「开发环境」「应用」页：本机缺的点「在本机安装 / 升级」，本机多的点「在本机卸载」，对面缺的点「复制命令」拿去那台跑

## 数据位置

| 位置 | 内容 |
|---|---|
| `~/Library/Application Support/sssync/config.json` | 本机配置（两台是谁、中转站、常驻） |
| `~/Library/Application Support/sssync/shared.json` | 同步清单的本机缓存（以中转站上的为准） |
| `~/Library/Application Support/sssync/blobs/` | 内容仓库（按 SHA-256） |
| `~/Library/Application Support/sssync/backups/<会话>/` | 被覆盖 / 删除前的原样 |
| `new:~/sssync-relay/` | 中转站：两边状态（含环境报告）、基线、待办、回执、`shared.json` |

## 开发

```bash
xcodegen generate                       # project.yml → sssync.xcodeproj
xcodebuild test -project sssync.xcodeproj -scheme sssync -derivedDataPath build
swift scripts/make-icon.swift out.png   # 重新生成 1024px 图标
```

- `Sources/SyncKit/`：引擎（对账、各类条目、中转站、自写 Myers diff 与三方合并、环境报告、录制）
- `Sources/App/`：SwiftUI 界面
- `Tests/SyncKitTests/`：对账、diff、合并、模板、环境对比等单元测试

没有第三方依赖：diff（Myers）和三方合并（diff3）都是自己写的。
